# Okta Change Auditor — how to use

1. **Pick an org** and a **time window**.
2. Read the table: **When**, **Who** made the change, **What** changed, the **Target**, and the **Outcome**.
3. **Filter** any column from its header; click a row for the full System Log event.
4. Routine noise (Okta system actions, bulk assignment churn) is hidden by default — use the
   toggle to show everything.

Read-only: the tool never writes to Okta.
